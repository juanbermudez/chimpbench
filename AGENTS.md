# AGENTS.md

ChimpBench (formerly MGOGO) is a 3D eastern-chimpanzee society simulation (Kibale-inspired) and a live demo of a local decision model, GLiNER2.5-Decide, choosing actions from the state a chimp perceives. Vite 8, TypeScript 7 strict, three.js 0.186 (WebGL), vanilla DOM UI, `node:test` via tsx. Git repo with a public remote (https://github.com/juanbermudez/chimpbench; history rewritten 5 October 2026, see HANDOFF.md); parallel agents work in git worktrees and the integrator merges.

## Architecture

| Layer | Files | Rule |
| --- | --- | --- |
| Contract | `src/types.ts` | Shared plain data. Add fields as optional and documented; never repurpose one. |
| Simulation | `src/simulation.ts` (public API), `src/sim/*` | Only writer of behavior, body and relationship state. |
| Clock | `src/clock.ts` | Runs whole fixed ticks within a frame budget; lockstep gate. |
| Decision loop | `src/decision.ts`, `src/providers/*` (browser GLiNER, server GLiNER, Jev gateway client; `packet.ts` is the one packet-text builder), `server/decide.ts` (HTTP bridge; re-exports the packet module), `server/jev.ts`, `server/local-worker.ts` | Roster, queue, traces; routes each request through the selected `DecisionProvider`; strict request validation (`src/sim/context-check.ts`); one resident worker. |
| Kernel contract (stage R1) | `src/kernel/*` (interface, kernels, answer check, between-tick loop, the decode step `decode.ts`), `src/sim/request.ts` (`buildRequest`), `src/sim/context-check.ts` (request validation), `scripts/lib/kernels.ts` (GLiNER adapter and stand-in behind the batch scorers) | A kernel only chooses: the request in, one option position out; no state, no random generator of its own. Every kernel but the in-simulation rules passes the same request validation, answer check and `applyDecision`. Jev is gated (approval and a call cap) and holds no key. Switches `kernelSim`, `kernelGate`, `kernelNoRulesPick` are 0 by default. Stage R2 (`docs/staging/r2-prereg.md`; `src/kernel/packet-words.ts`, `packet-rules.ts`; all 0 by default): `observeV4` (more of the state in the packet, words before numbers), `menuParity` (every kernel's menu is the rules' menu), `activityFirst` (one entry per kind of activity, then the target), `kernelSim` 2 (the packet-reading rules). Stage R7 (`docs/staging/r7-prereg.md`; the defaults are today's behaviour): `kernelNullShare` (under `kernelSim` 1, the share of decision points the null kernel takes, the rest going to the rules; default 1), `kernelFocal` (1: the in-tick kernel decides only for animals marked `controller: 'model'` with the model policy off; default 0). Stage R8 (`docs/staging/r8-prereg.md`; `src/sim/own.ts`, `src/kernel/packet-own.ts`; 0 by default): `observeV5` (packet 5: the animal's own experience in the observation and the packet, neutral option labels, none of the rules' wording; the loop keeps `chimp.sim.own`, which nothing but `observe()` reads), with `ownKeep` (how many closed trips, crowns and grooming partners that record keeps; default 8). Stage R9 (`docs/staging/r9-prereg.md`): which option is applied is a decode step of the loop, not of the kernel (`src/kernel/decode.ts`: `top`, `draw`, `held`; pure, nothing to fit, never `world.rng`), passed to `answerWaiting` as `decode` and absent by default; a held draw's epoch is the harness's (`scripts/lib/decoder.ts`). |
| Rendering | `src/scene.ts`, `src/render/env/*`, `src/render/creatures*` | Reads World, never writes it. |
| Audio | `src/audio/*` (`mix.ts` pure math, `engine.ts` Web Audio) | Reads World and `scene.getListener()`; never writes either. |
| Persistence | `src/persist/*` (envelope, schema, store worker, controller), `src/ui/simulations.ts` | Serializes World, never mutates it; only `main.ts` swaps the World object (open/new). SQLite WASM + opfs-sahpool in a worker. |
| UI | `src/main.ts`, `src/ui/*`, `src/style.css` | Reads World; writes only control fields (`chimp.controller`, `world.modelPolicy`, `world.ageRate`) through the APIs. |

Frame loop order (in `src/main.ts`): `pumpDecisions` → `advance` (clock runs `tickWorld`) → `scene.update` → `audio.update` (20 Hz inside) → throttled UI → `persist.tick` (autosave; one snapshot slice per frame, during which pump and clock hold).

## Invariants (do not break)

- **Determinism.** All sim randomness comes from `world.rng`; no `Math.random` in `src/sim`. `tickWorld` always advances exactly `TICK_SECONDS` (15 s). The same seed and tick count give a deep-equal world however ticks are batched. `observe()` and `rulesChoice()` are pure: no RNG use, no mutation.
- **Speed never changes the tick.** Faster playback runs more ticks per frame; the clock reports `limited` when the budget caps it.
- **The model only chooses.** Code builds legal candidates, validates the answer, and re-checks legality before applying. `observe()` is local-only (no unseen entities). The server accepts no client instructions. The GHN checkout (`MGOGO_GHN_ROOT`; `~/Desktop/GHN` by default, `/Volumes/Drive/chimpbench/GHN` on this computer) is read-only and identity-checked by source hash.
- **Evidence labels.** Every new behavioral constant is tagged `[H]`, `[M]`, `[L]` or "design assumption" in a comment. Cite only sources in `docs/research.md`, and add new sources there first. Label stylizations in code and docs.
- **Performance.** Keep the sim bench target and 60 fps at 1440×900. No per-frame allocation in render loops; use instancing and shared materials.

## Conventions

- **Coordinates:** +x is east, −z is north, y is height above ground. The app's new and scratch worlds use the field profile (8 km in real metres, stage C5a/C5b); `?profile=compressed` or Simulations › New › Compressed opens the 160 m map, and saves keep their own profile. `createWorld(seed)` still defaults to compressed (tests, golden hashes and scripts rely on it); pass `{ profile: 'field' }` for the field map. Browser probes that need the small map pass `profile=compressed` (perf-probe does unless `--query` names a profile).
- **Id ranges:** chimps < 100000, trees 100001+, water 200001+, prey 300001+, dynamic ids (interactions, calls, stimuli) 1,000,000+.
- **Time:** `world.time` is ecological hours since 06:30 on 28 Sep (day-of-year 271). Life history runs on a separate clock scaled by `world.ageRate`.
- **Plain-data extras:** internal sim state lives in `world.sim` / `chimp.sim`. It is serializable and part of determinism checks.
- **Saves:** World must stay JSON-lossless (no Map/Set/class instances, `undefined` values, non-finite numbers or shared references; `tests/persist-envelope.test.ts` guards it). Changing `ChimpX`/`SimState` keys changes `STATE_SHAPE` and marks older saves incompatible (by design during the realism program; no migrations). Bump `STATE_VERSION` in `src/persist/envelope.ts` when a field keeps its name but changes meaning. Keys a mechanism adds lazily must be listed as optional for the load-time shape check (`OPTIONAL_*` in `src/sim/state.ts`; the field-profile ones in `LAZY_*`, `src/persist/envelope.ts`), or saves made after it fires are refused.
- **Troop fields:** `troop.alphaId` is `-1` during a contested vacancy (up to 48 h). Since stage C6 `troop.center`/`radius` are the use-weighted centre and equal-area radius of the 95% utilization isopleth (`troop.range`, updated daily by `src/sim/territory.ts`); nothing scripts range shifts.
- **Interventions:** `applyIntervention(world, kind, { troopId, position })` treats `position` as the observer's focus. Each protocol places its stimulus relative to it.
- **Naming:** the product is ChimpBench. Env vars (`MGOGO_*`), debug hooks (`__MGOGO_*__`), storage keys and names (`mgogo.sqlite3`, `mgogo-pool`, `mgogo-store`, `mgogo:uncapped`, `mgogo.sidebar`, `mgogo.chimp`, `mgogo.sound.v1`) and shader/material flags and cache keys stay `MGOGO`-prefixed on purpose, for compatibility with saves, settings, scripts and running sessions; don't rename them. Exports are `.chimpbench.json.gz`; `.mgogo.json.gz` still imports.
- **Terminology:** use "community" in UI and docs ("troop" is baboon usage) and "party" for temporary subgroups. The code type is still `Troop`.
- **Style:** compact TypeScript, comments explain why. Match surrounding code. No new npm dependencies without strong reason (three/addons are available).

Only one model process may run at a time, across every checkout: a worker holds about 2 GB at rest on this computer (HANDOFF.md §3) and a training 6 to 7 GiB (IMPLEMENTATION_PLAN.md, stages R4 to R11), and the night scripts refuse to start beside another.
- While a model step waits on a worker's answer (a scoring, loop or population step: its model load and warm-up, then its registered asks), run no whole test suite and no heavy build on this computer, and start no second agent that does. On 12 October 2026 a loop step of stage R11 failed because its worker gave no answer to the warm-up packet in the 600 s allowed, while three agents ran test suites at once (1-minute load 14); the step had written nothing and was run again (`docs/staging/r11-prereg.md` §14.1). Nothing may bake community spacing or patch density: read `world.troops` / `world.trees`.

- Creature playback trails the sim by 2 ticks (`motion.ts` needs a sample on both sides of the drawn segment). Per-animal shader params live in texels P0..P6 (`ROW_TEXELS` 132; stage W8 took texel 130); a new texel beyond 131 means raising it.
- Which act the drawn body is in (stages W4 and W6, `render/creatures/drawn.ts`): the creature layer reads it once a frame for every animal into `Anim.act`, `Anim.actTarget` and `Anim.way`, and poses, pairings, the waterline, the nest place and the name tags all read those, never `chimp.action`, so a pose cannot run ahead of its tag. A stationary act is announced until the body's own drawn time reaches it and then for as long as the body is on its way ("walking to drink", "climbing to feed"); a trip until the drawn path moves, at most 6 ticks. An urgent act (`BODY_SIGN` 'any': a call, a charge) is drawn and ended with the simulation. A body that has set off for an act it has not reached is read as on the move (`a.act` is `travel`, no target). New clip and gaze logic reads `a.act`; code that needs the simulation's act for something else (sound, links, the party marks) keeps `chimp.action`. The act a body "is still in" must be one it was drawn in a moment ago: the record notes acts drawn without an announcement (`plain`) and acts whose start fell in skipped states (`unseen`, `SKIP_TICKS`: a fast-forward, `__MGOGO_TEST__.tick`), and a tree or nest place remembered from an act the simulation has left is used only within 30 m of the drawn body. Without these an animal was drawn asleep at its nest tree a kilometre from where it was. `scene.drawnAct(id, out)` reports it to the interface; it writes nothing to the World.
- The decision beat (stage W6, `render/creatures/beat.ts`, `intention.ts`): for an animal whose act changed in the last 8 drawn ticks, the gaze goes to a close runner-up, then to the chosen target, then an intention overlay plays, in the 3.4 real seconds before the body starts; followers of one departure are sampled up to 1.5 ticks behind their own path (`Anim.late`) so they set off in the order chosen; only a body that starts from rest is held, and never once it has set off. Every per-animal drawn time is `playback.renderT - a.late`. Off above 2 min/s. What counts as on the move follows the world's walking speed (`drawn.ts` `movingMps`: the 160 m map walks at 0.04 m/s). All stylizations. Probes that jump the clock must land at least three ticks before the act they film, or it has no beat.
- The state on the body (stage W8, `render/creatures/bodystate.ts`): the creature layer reads each animal's state about once a second into `Anim.tg` and eases it into `Anim.ch`; it never opens `chimp.sim`. Public fields give the channels on the default world (belly from 1 − hunger, lid from 1 − energy, coat from stress above 0.3 and the mood); where a Track E mechanism runs, `bodyStateOf(world, chimp)` in `src/simulation.ts` gives the `BodyPercept` instead. The reader stores nothing and allocates its record: call it about once a second per animal, never per frame. On the default world lids never droop (energy stays above 0.8). An infant is placed on its carrier's skeleton, not on the drawn surface, so anything that swells a carrier must give way under it: `Anim.bears` says what rides on an animal this frame (bit 1 on the belly, bit 2 on the back), and `bellyUnder` and `coatUnder` hold the belly and the coat down there, in every seat. Shader parameters: `P2.x` is a signed coat value (−1 sleek .. 1 on end, up to 2 for an animal small on screen), `P5.z` the upper lid, texel 130 (`P6`) belly, flank and breath; free are `P5.w`, `P6.w` and texel 131. The coat, belly and breath are in `SKIN_VERTEX`, which the colour, shell, shadow and silhouette passes share (`tests/render-bodystate.test.ts`): a displacement added elsewhere casts no shadow. The gain for a small animal is written from the main camera's view, so `portrait()` writes the ungained coat for its own draw (`coatNear`): anything else scaled by on-screen size needs the same. Every mapping is a stylization.
- Idle life (stage W8, `render/creatures/secondary.ts` `idleStep`, `render/creatures/idle.ts`): one-shot scratches, yawns, weight shifts, glances and nods over stationary clips, hash-scheduled per animal; breathing on every living animal. `creatures.ts` `IDLE_ALLOW` says which clip permits which event: a new stationary clip needs a row (an unknown one gets yawn and glance, or everything if its name begins with rest, sit or perch). The posture is read from the pose (`intention.ts` `postureOf`). No event starts or goes on while the body moves, during a decision beat, while an initiator waits, while a call is listened to or above 2 min/s. The idle glance is the lowest gaze: it only takes the place of the aimless idle scan, and a new gaze source goes in front of it. A turn that starts and cannot be drawn must be used up, not cancelled (stage W11, `secondary.ts` `idleSpend`: a glance with no neighbour within 9 m; a cancelled turn is drawn again after 2 s, which made an animal alone busier than one in a party). An event ended early must not drop out of the pose: a yawn or a nod cut short sets `idleCut` and `evaluatePose` starts the pop guard's blend (`idle.ts` `idleFace`); a scratch cut short lets go along the curve a finished one ends on (`idle.ts` `scratchRelease`; the arm keeps its own record of the scratch in `Anim.scr*`, and the body's part follows through `IdleCtx.letGo`); a new event kind that moves the head or the face belongs in `idleFace`.
- Where idle life meets a crown (the merge of stages W8 and W9; pure rules in `idle.ts`, held by `tests/render-idle.test.ts`): a hand that holds on does not scratch (`handHolds`: placed by IK and overhead, or closed round a support, finger curl above `GRIP_HELD`; a clip that keeps a hand on something must curl its fingers with `grip`, or a scratch takes that hand); a body lying along a bough does not scratch (`mayScratch`); the resting seat stands in for acts that have no clip in a crown (a display, a submission, a pant-grunt) and has idle life only in a quiet act (`seatIdles`, asked with `a.act`); nothing starts on a body still sliding to its seat (`Anim.glide`, set by `placeGrounded`). Feeding permits a weight shift and a glance only, so the hands on the cluster are never taken.
- An animal in a tree is placed and looked up by where its body is DRAWN (`treeFor` uses the track, not `chimp.position`): the simulation is two ticks ahead and has left the tree while the body is still coming down its trunk. `Anim.trunkK` eases a body onto the bark whenever its drawn path goes up or down, whatever its act.
- Seats in crowns (stage W9, `render/creatures/perch.ts`, `creatures.ts` `layoutCrowns`): an animal off the ground sits at its own place (`ownSeat`: a limb the environment draws, else out from the crown anchor) unless the layout seats it on a bough (`Anim.seatHost`): everyone joined by pairings in the crown of one tree shares one level bough laid at one member's place (`seatGroups`, pure and tested), an animal whose place is inside another's body joins that animal's bough, and an animal drawn lying gets one along its body (not with a body seated within its own length). The bough is the branch prop, never a limb of the tree; since stage W11 it is drawn as one (`emitProps`: two tapered halves forking at the host's seat, a stem from the nearest limb the environment draws or from the bark, `perch.ts` `boughStem`, in the colour of the tree's limbs: the optional context hooks `limbNear` and `barkColor`, answered by `env/vegetation.ts` and the harness). A seat is refused when it is more than 9 m from the animal's simulated position and further than its own branch (`seatAllowed`). The drawn seat eases to its place (`Anim.sx/sy/sz`), then goes through stage W6's blend with the trunk; the nest place is a seat too. Stage W11: whatever the place, the drawn body goes there no faster than a clamber plus what its own drawn path moves in the frame (`perch.ts` `crownStep`, 2.5 m/s up to Watch 4x; `Anim.cx/cy/cz`), and more than a metre from the place it is bound for it is drawn in the `clamber` clip (`Anim.clamber`; `chooseClip` returns it before everything but a carried or dead body, and inside the nest branch after the nest's progress is worked out). No clamber above 2 min/s and none on a carried body (`perch.ts` `clambering`; second reading of stage W11). A clambering body has one heading, its line of travel: the decision beat's turn to the goal, the turn to the trunk and the motion step's turn along the simulated path are all off while `Anim.clamber` is set, or it trembles when frame times are uneven. A paired actor's clamber clip is returned with its pairing's role. Whether a path is on its trunk is one rule (`perch.ts` `trunkBound`) that the crown layout (`Anim.up`) and the placement (`Anim.onTrunk`) ask of the same frame's path: read a frame late, a partner that had set off still crowded the animal it left onto its bough for one frame, and that animal was drawn clambering. A place is drawn at once in five cases: after a relocation, on a first frame in a tree, above 2 min/s, in the frame the forest window gives or takes the tree's limbs (`Anim.ownCut`), and more than 14 m away. A place that depends on the clip must hold while the clamber clip replaces that clip, or the body goes to and fro (the nest's progress `nestK`, `Anim.lies`). The tag of a body clambering to a partner's bough reads "going to" (`Anim.tagWay`, which the tags and `drawnAct` get in place of `Anim.way`; body logic keeps `way`). Pairings are formed from the two drawn paths (`perch.ts` `pairReach` on `Anim.track`), never from simulated positions, and not with a body on its trunk or one that has set off on a trip.
