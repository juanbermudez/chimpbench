# R15 training contract

Registered before teacher execution, 13 October 2026. This implements the narrow scope in r15-perceived-targets.md. No R15 model is loaded while R14 runs.

The live renderer and exporter use `r15Packet`, identity `resource-targets-v1`. Serializable context phase/kinds survive HTTP, JSON export and replay. Kind criteria contain fixed neutral activity words; target criteria use P5b neutral resource descriptions. Kind packet state is rendered without candidate targets so representative identity cannot change its social-timing selection or truncation. Both retain body, ongoing act and own-experience fields; this is a new packet, never an R11/R14-compatible adapter.

At each selected fresh decision, emit one kind row and at most one resource-target row, selected by a deterministic hash among multi-target resource groups before labels. The kind teacher is R11's original-menu conditional distribution, summed into offered kinds and normalized; excluded kind mass is reported, not silently credited. It requires the existing 2,000 minimum / 20,000 maximum redraws, target 500 same menus and minimum 100. Learner asks do not claim realized teacher RNG/pick reconstruction. Kept/arrived choices are not fresh labels.

The resource-target teacher is counterfactual valuation imitation on the fixed shown menu: each option retains its current rules raw value including persistence, plus redrawn uniform candidate jitter and the existing belief distribution, then the published-score clamp/rounding and maximum. Use 2,000 deterministic redraws keyed by record ID, canonical action/target tie order, and no world RNG. This teacher is not the original rules' choice probability on a wider menu and is not an ecological reward or wild preference. Its finite sample can assign zero to rare alternatives; report counts and redraws. Body/social gates stay unchanged. Scores, reasons and teacher diagnostics never enter packets.

Each row records parent decision, seed, animal, split, phase, exact packet and context hashes, teacher and normalized soft label. Training/development use existing animal split on 48/7, seed21 evaluation only; phases of one decision stay together. Assembly rejects duplicate rows, split leakage, incorrect packet/context parity and identity mismatches. It writes new files and a manifest; it never mixes old flat packets. The unchanged R11 soft-label trainer trains a newly named R15 adapter from base, three epochs, seeds7/11 separately. The wrapper checks data hashes/identities and R14's lock/state plus running model processes before importing any model module. Its default prints the exact command; explicit run is guarded. No old-adapter compatibility claim.

Focused checks use synthetic valid contexts and small pure teacher draws only. Production collection, tokenizer counts, model parity, training, cost and behavior validation remain future work after R14 is idle.
