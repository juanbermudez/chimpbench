Credits

The tools, decision models, sound and field data behind ChimpBench, then the studies it draws on. Full notes are in research.md and simulation.md.

Built with

  • three.js · 3D rendering · MIT
  • SQLite WASM · @sqlite.org/sqlite-wasm, saves in the browser
  • math (pmndrs) · small vector helpers, used for the Vec3 type · MIT
  • Vite · build and dev server
  • TypeScript · the language
  • AMD FidelityFX Super Resolution 1 · upscaling, ported to WebGL in src/render/env/post.ts; © 2021 Advanced Micro Devices · MIT
  • Web Audio · the browser API that mixes the sound
  • Fraunces · display font, from Google Fonts · SIL OFL
  • Instrument Sans · interface font, from Google Fonts · SIL OFL
  • JetBrains Mono · numbers and code, from Google Fonts · SIL OFL

Decision models

  • Rules · built into ChimpBench: a simple recipe scores each legal option
  • GLiNER2.5-Decide by Fastino · the small model the app runs live, on your computer · Apache 2.0
  • gliner2 · Fastino's library that loads and runs it
  • DeBERTa-v3-large by Microsoft · the encoder GLiNER2.5-Decide is built on
  • PyTorch · runs the model
  • Hugging Face Transformers · model code underneath
  • Trained adapters (LoRA) · three temperaments of GLiNER trained for this project, with Hugging Face PEFT
  • Jev by TypeSafe · a System One model, tested offline only; its answers are never used for training

Sound

The chimpanzee calls and the rainforest ambience in the app and in the guide come from the Epidemic Sound library, under the project owner's licence. Buttress drumming is synthesized in code.

  • Epidemic Sound · recorded calls and forest ambience · licensed
